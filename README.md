# Progress Document: FlappyPlane

Unity Play Link: https://play.unity.com/en/games/515ad91b-137e-4151-ac4e-4a8dd52d0bb2/flappyplane

## Project Title & Description
FlappyPlane is a 2D endless runner game inspired by the classic "Flappy Bird." The player pilots a plane, navigating through a continuous series of obstacles. The core objective is to survive as long as possible to achieve a new high score.

## Features Completed 
-  Player Physics: Implemented gravity and upward impulse mechanics (jump) for the plane
-  Level Generation: Infinite scrolling background and continuous obstacle spawning
-  Collision Detection: Box colliders for detecting crashes
-  UI System: Functional Main Menu, Heads-Up Display (current score), and Game Over screen with a "Restart" button.
-  Score Tracking: System counts +1 for every obstacle pair passed.
-  Asset Integration: Generated by Gemini and then edited to make a transparent background with an online tool
  
## Known Issues

## How to Play
1. Navigate to the unity play link
2. Press any button to start the endless runner
3. Make the plane 'jump' by either left clicking or pressing the space bar
4. Reach the highest score you can
5. Restart as many times as you'd like
