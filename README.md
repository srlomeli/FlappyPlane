# Final Release: FlappyPlane

Unity Play Link: https://play.unity.com/en/games/515ad91b-137e-4151-ac4e-4a8dd52d0bb2/flappy-plane

## Project Title & Description
FlappyPlane is a polished 2D endless runner game inspired by the classic "Flappy Bird." The player pilots a plane, navigating through a continuous series of progressively difficult obstacles. The core objective is to survive as long as possible to achieve a new high score.

## Features Completed (v1.0) 
- Player Physics: Implemented gravity and upward impulse mechanics (jump) for the plane.
- Level Generation: Infinite scrolling background and continuous obstacle spawning. Pipes are consistently spaced at a fixed distance of 8 units.
- **Progressive Difficulty**: The plane's movement speed increases gradually over time, ensuring the game becomes more challenging as the player's score rises.
- Collision Detection: Upgraded to a Polygon Collider for more realistic and accurate crash detection, addressing a known limitation in the previous build.
- UI System: Functional Main Menu, Heads-Up Display (current score), and Game Over screen with a "Restart" button.
- Score Tracking: System counts +1 for every obstacle pair passed.
- Asset Integration: Generated by Gemini and then edited to make a transparent background with an online tool.
  
## Known Limitations
- Simple core mechanic: The game could be expanded with more player characters, collectible items, or power-ups for deeper player engagement (future development idea).

## How to Play
1. Navigate to the unity play link.
2. Press any button to start the endless runner.
3. Make the plane 'jump' by either left clicking or pressing the space bar.
4. Reach the highest score you can.
5. Restart as many times as you'd like.
